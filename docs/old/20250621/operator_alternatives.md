# PyProlog 演算子代替案

## 問題のある演算子と代替案

### 1. 非同一性演算子
**問題**: `\==` (パースが困難)
**代替案**: `<>`、`!=`、`neq`

```prolog
% 現在（問題あり）
X \== Y

% 代替案
X <> Y     % 多くのプログラミング言語で使用
X != Y     % C言語系でポピュラー
neq(X, Y)  % 述語形式（最も確実）
```

### 2. 非単一化演算子
**問題**: `\=` (パースが困難)
**代替案**: `<>` または述語形式

```prolog
% 現在（問題あり）
X \= Y

% 代替案
X <> Y           % 同一性用と統一
not_unify(X, Y)  % 述語形式
```

### 3. 算術非等価演算子
**問題**: `=\=` (パースが困難)
**代替案**: `<>` または `!=`

```prolog
% 現在（問題あり）
X =\= Y

% 代替案
X <> Y     % 統一した記法
X != Y     % 直感的
```

## 統一された演算子体系

### 提案する演算子セット

```prolog
% 等価性
X = Y     % 単一化
X == Y    % 同一性
X =:= Y   % 算術等価

% 非等価性（統一記法）
X <> Y    % すべての非等価に使用
X != Y    % 代替記法

% 比較
X < Y, X > Y, X =< Y, X >= Y  % 既存のまま
```

## 実装上の利点

### 1. パーサーの簡素化
- バックスラッシュ処理が不要
- トークナイズが単純
- エラーの可能性が大幅減少

### 2. ユーザビリティの向上
- 他言語経験者にとって直感的
- タイピングが容易
- 覚えやすい

### 3. 保守性の向上
- バグの可能性が低い
- テストが容易
- 拡張が簡単
